DropShip v0.7 — 작은 우주 배송
라이 × 코스 / COSRAI

이번 버전의 변화
• 웃는 우주선 ‘드로피’와 연보라·민트 테마
• 둥근 버튼, 받는 기기 강조, 더 또렷한 보내기 버튼
• 기기 선택 → 파일 담기 → 출발! 순서로 화면 정리
• 수동 IP 설정 접기/펼치기
• Android의 선택된 탭 표시, 최근 배송 기록 접기/펼치기
• PC의 빈 대기열 안내와 새로운 앱 아이콘

PC에서 업데이트
1. 기존 DropShip을 종료합니다.
2. DropShip_v0.7.exe를 실행합니다. 별도 .NET 설치는 필요 없습니다.
3. 등록된 기기와 받을 폴더를 확인합니다.
4. 우클릭 전송 기능을 사용하면 ‘받기 / 내 기기’에서 우클릭 메뉴를 다시 등록합니다.

Android에서 업데이트
1. 기존 앱을 삭제하지 말고 DropShip_v0.7.apk를 설치합니다.
2. 설치 후 등록된 기기, 받을 폴더, 대기열을 확인합니다.
3. 앱 표시 이름은 DropShip입니다. 앱 내부에 v0.7이 표시됩니다.
4. Android 10 이상. 기존 v0.6과 동일한 패키지 ID 및 개발 서명을 사용합니다.

보내기
양쪽 앱 실행 → 같은 Wi-Fi 연결 → 받을 폴더 확인
→ 처음 연결이라면 기기 찾기와 양쪽 연결 승인
→ 받는 기기 선택 → 파일 또는 폴더 추가 → 보내기 / 이어보내기
기기를 누르거나 파일을 담는 것만으로 자동 전송되지 않습니다.

받기
‘받기’ 화면에서 받을 폴더를 선택하고 앱을 켜 둡니다.
폰은 전송 중 화면과 앱을 계속 켜 두세요.
검색이 안 되면 보내기 화면의 ‘수동 IP’ 버튼을 펼쳐 입력합니다.

유지한 기능
기기 등록·별명, 폴더 전송, 중단 후 이어보내기, 이름 충돌 처리,
SHA-256 검증, 오류 복사, Android 공유 메뉴, PC 드래그 앤 드롭.
전송 규약과 기존 설정 저장 위치는 바꾸지 않았습니다.
기존처럼 로컬 네트워크 전용이며 전송 암호화·인터넷 전송은 추가하지 않았습니다.
