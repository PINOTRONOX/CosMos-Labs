# v0.7

연보라·민트 테마, 드로피 캐릭터와 아이콘, 둥근 버튼, 단계별 보내기 화면, 수동 IP 접기/펼치기, Android 탭 선택 강조 및 기록 접기. 전송 코어 및 기존 설정/서명 유지.

# 변경 기록

## v0.6.0 — 2026-10-07

- 등록된 기기를 클릭해 상대 한 대를 선택하고 연결·기기 ID 확인.
- 모델명 뒤 괄호 별명, 로컬 저장·수정·삭제.
- 받는 기기 표시, 전송 중 대상 잠금, IP 재할당으로 다른 기기가 응답하면 차단.
- Android 첫 받는 폴더 안내, 폴더 미설정·권한 상태의 송신 전 확인.
- 실패 원인·HTTP 코드 유지, 오류 복사, 수신 실패 기록.
- v0.5 앱 ID·서명·등록·폴더·대기열 저장 경로 유지. 파일 전송 규약 2 및 검색 규약 유지.
- 암호화·백그라운드·동시 여러 기기 전송은 추가하지 않음.

## v0.5.0 — 2026-10-06

기기 승인, 폴더와 빈 폴더, 청크 기반 이어보내기, Windows 우클릭 및 Android 공유를 통합한 테스트 버전.
